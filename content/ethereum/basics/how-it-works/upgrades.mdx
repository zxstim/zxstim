Ethereum has upgraded more than twenty times since it launched in 2015: changing how fees work, switching to proof of stake, making Layer 2 cheaper. But no company, CEO or token vote decided any of those changes.

## Every change starts with an EIP

An **EIP** (Ethereum Improvement Proposal) is a document that describes a change. Anyone can write an EIP and put it up for public discussion.

- **Core EIPs** change the protocol itself, like EIP-1559, which changed how fees work. These need the whole network to upgrade.
- **ERCs** are standards for applications, like ERC-20 for tokens or ERC-721 for NFTs. These don't need a network upgrade.

## From proposal to mainnet

1. **Write the proposal.** The author writes the EIP using a shared template.
2. **Present it publicly.** The EIP is brought up in the development teams' open meetings (All Core Devs), which anyone can watch.
3. **Revise and polish** it based on feedback.
4. **Bundle it into an upgrade.** The teams pick the EIPs that are ready for the next upgrade.
5. **Test, then activate.** Each software team makes the change in its own software. The upgrade is tested on testnets (such as Sepolia and Hoodi), then activated on mainnet at a point set in advance.

## Who decides?

Ethereum is governed offchain: there's no vote with ETH. Decisions take shape through discussion among many groups: developers, node operators, validators, app developers and users.

Developers can't force anyone to upgrade. Each node operator chooses their own software. If most of them don't agree with a change, they don't install the new version, and the change doesn't take effect.

When the upgrade point arrives, nodes that have updated switch to the new rules. Nodes that haven't updated can't check the new blocks and get split off from the network. In 2016, after The DAO incident, a group that disagreed with the upgrade stayed on the old chain, and that chain became Ethereum Classic.

<Callout type="warn" title="Warning">
Regular users don't need to do anything when Ethereum upgrades: your ETH and tokens stay exactly as they are. Anyone who tells you that you have to "upgrade" or "swap" your ETH is running a scam.
</Callout>

## Major upgrades

| When | Upgrade | Main change |
|---|---|---|
| July 2015 | Frontier | Ethereum launches |
| July 2016 | DAO fork | Recovers the funds drained from The DAO; Ethereum Classic splits off |
| December 2020 | Beacon Chain | The proof-of-stake chain launches, running alongside |
| August 2021 | London | EIP-1559: the base fee is burned |
| September 2022 | The Merge | Full switch to proof of stake |
| April 2023 | Shapella | Validators can withdraw their stake |
| March 2024 | Dencun | Blobs: Layer 2 gets much cheaper |
| May 2025 | Pectra | Regular accounts can be upgraded into [smart wallets](../using-ethereum/smart-wallets.mdx) (EIP-7702); one validator can hold up to 2,048 ETH |
| December 2025 | Fusaka | PeerDAS for more blobs; default gas limit of 60 million; passkey support |

Upgrade names combine the name of a city that hosted a Devcon conference (for the execution layer) with the name of a star (for the consensus layer). For example, Glamsterdam is Amsterdam combined with Gloas.

## Coming up

The roadmap can change. As of November 2026, the two upgrades below are not yet on mainnet:

- **Glamsterdam** has run on the Sepolia testnet since October 6, 2026, but has no date yet for the Hoodi testnet or for mainnet. Two main changes:
  - Building the separation of proposers and block builders into the protocol itself (ePBS, EIP-7732), so it no longer depends on MEV-Boost relay nodes.
  - Block-level access lists (BALs, EIP-7928), which help nodes run transactions in parallel.
- **Hegotá** has no date yet. Two changes have been scheduled for it: FOCIL (EIP-7805), which helps resist transaction censorship, and a new kind of transaction, frame transactions (EIP-8141), which let smart wallets set their own rules for checking signatures and paying fees.

The full list, and how a change goes from an EIP to mainnet, is in [The roadmap and how the protocol changes](../../developers/protocol/roadmap.mdx) in the Developers section.

In the long run, Ethereum's roadmap aims for cheaper fees, more security, easier use and privacy by default.

## Summary

- Every change starts with a public EIP, discussed in open meetings.
- Many software teams build it together, test it on testnets, and then the whole network upgrades at a point set in advance.
- No one can force node operators to upgrade. Regular users don't need to do anything.

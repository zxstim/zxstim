A **smart contract** is a computer program stored on a blockchain. It follows "if this happens, then do that" logic, and it always runs exactly as its code is written. This is what sets Ethereum apart from Bitcoin: besides moving money, Ethereum can run applications.

Computer scientist Nick Szabo coined the name back in 1994. He imagined a digital marketplace where agreements carry themselves out, with no need for a trusted middleman. Ethereum made that idea real.

## Like a vending machine

Think of a drink vending machine:

1. You pick an item.
2. The machine shows the price.
3. You pay.
4. The machine checks whether you've paid enough.
5. If you have, it drops the item. If not, it doesn't.

No seller needs to stand next to it. The rules are programmed into the machine, and they work the same way every time. A smart contract is the same: put in the right conditions and you get the result that was set in advance.

For example, you could write a contract that holds savings for your child and only allows withdrawals after a certain date. Try to withdraw earlier and the contract won't go through. No bank is needed, and no one can change their mind halfway.

## Where does a contract live?

A smart contract is a kind of [account](./addresses-and-keys.mdx): it has an address and a balance, plus two more things:

- **Code**: the contract's functions, for example "transfer tokens".
- **Data** (state): what the contract remembers, for example each person's token balance.

A contract has no private key. No one can sign on its behalf; it just follows its code. A contract also doesn't run on its own: it only runs when someone sends a [transaction](./digital-signatures.mdx) that calls one of its functions.

## What makes smart contracts special?

- **Automatic and predictable.** A contract runs exactly according to its code, with no one needed to interpret it. Two judges might read a paper contract two different ways; a smart contract can only be read one way.
- **Public.** Anyone can see the code and every transaction that has called the contract.
- **Permissionless.** Anyone who can code can **deploy** a contract to Ethereum. Deploying is also a transaction, so all it takes is paying the gas fee.
- **Composable.** Contracts can call other contracts, like Lego bricks. A token exchange calls token contracts; a lending app uses prices from another contract. That's why new apps can be built very quickly on top of what already exists.
- **Hard to change after deployment.** By default, a contract's code can't be changed. This helps users trust that the rules won't be switched on them. Some projects use designs that allow upgrades (the proxy pattern, for example), which means someone holds the power to swap out the logic. When you use an app, it's worth knowing who holds that power.

## What are smart contracts used for?

Almost anything a computer program can do. The most common uses:

| Use | What the contract does |
|---|---|
| Tokens, stablecoins | Records each person's balance and allows transfers, like USDC |
| Decentralized token exchanges | Swaps one token for another using a formula, with no one needed to match orders |
| Lending | Holds collateral. When its value drops too low, anyone can call the contract to liquidate it |
| NFTs | Records who owns each unique digital asset |
| DAOs | Lets members vote, and carries out the result according to the agreed rules |
| Smart wallets, multisig wallets | Requires several signatures to move money, or sets spending limits |

## Limits to know about

- **They don't know about the outside world.** A contract can only read data on Ethereum. To know the price of gold or the result of a match, it needs an **oracle**: a service that brings outside data onto the blockchain. A contract is only as safe as the oracle it trusts.
- **Buggy code fails exactly as written.** A contract does exactly what it was written to do, bugs included. Attackers can exploit bugs to drain funds, and because the code is hard to change, the losses usually can't be recovered. In 2016, a bug in The DAO contract let 3.6 million ETH be drained.
- **Every run costs gas.** The more complex the code, the higher the fee.

## Summary

- A smart contract is a program plus data, sitting at an address on Ethereum.
- It only runs when a transaction calls it, and every node gets the same result.
- An instruction that breaks the rules in the code is reverted, but the gas fee is still lost.
- Contracts are public, permissionless and composable, but bugs in the code can cost users money.

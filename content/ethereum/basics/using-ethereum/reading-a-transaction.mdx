Ethereum has no hotline you can call to ask "has my money arrived yet?". But because all the data is public, you can check for yourself with a **block explorer**: a website that shows transactions, blocks and addresses on Ethereum.

There are many block explorers. Etherscan is the most widely used. Blockscout and Otterscan are open source. Beaconcha.in shows the consensus layer (slots, epochs, validators). Ethplorer specializes in tokens and has a Vietnamese-language interface. All of them are run by third parties and read from the same blockchain.

## What's on a transaction page?

Paste the **transaction hash** into the search box. Wallets usually show a "view on block explorer" button after you send.

| Field | Meaning |
|---|---|
| Status | Pending, successful or failed |
| Block | Which block contains the transaction. See [Blocks](../how-it-works/blocks.mdx) |
| Timestamp | When the block was created |
| From, To | The sending address and the receiving address. "To" can be a [smart contract](../how-it-works/smart-contracts.mdx) |
| Value | How much ETH was transferred |
| Tokens transferred | If the transaction moved tokens, this shows which token, how much, and to whom |
| Transaction fee | The total fee paid. Part of it is burned, the rest goes to the validator |
| Gas limit, gas used | The most gas you allowed, and how much was actually used. See [Gas](../how-it-works/gas.mdx) |
| Base fee, priority fee | The price per unit of gas, in gwei |
| Nonce | The sending address's transaction number, counting from 0. See [Digital signatures](../how-it-works/digital-signatures.mdx#nonce-each-transaction-runs-only-once) |
| Input data | The instruction sent to the contract. If the contract's source code has been published, the block explorer decodes it into a readable name |

## Is the transaction final yet?

"Success" means the transaction is in a block. About 13 to 19 minutes later, that block reaches [finality](../how-it-works/blocks.mdx#when-can-a-block-no-longer-be-reversed) and becomes practically irreversible. Pages for blocks and epochs usually say clearly whether a block has been finalized yet.

- **Pending**: the transaction isn't in a block yet, usually because the priority fee is too low, or because an earlier transaction of yours (with a lower nonce) is still stuck.
- **Failed**: the transaction made it into a block but was reverted, for example because it ran out of gas or the contract rejected it. You still pay the fee for the part that ran.

## Address pages and block pages

- **An address page** shows the ETH balance, the tokens held and the full transaction history. Anyone can see it: see [Privacy](./privacy.mdx).
- **A contract page** also shows who created it, the creation transaction, and the source code if it has been published.
- **A block page** shows the block number, time, number of transactions, gas used out of the limit, base fee, how much in fees was burned, and the hash of the parent block.

## Using a block explorer to protect yourself

- **Check whether a token is real.** Anyone can create a token with any name. Get the official contract address from the project's own site and compare it on the block explorer.
- **Check and revoke spending permissions.** Tools such as Revoke.cash or Etherscan's token approval checker list the contracts you have allowed to spend your tokens. Revoking a permission doesn't cost you your funds.
- **Report scam addresses** on sites such as Chainabuse.

The labels a block explorer puts on an address ("scam", an exchange's name…) are for reference only, not absolute truth.

<Callout type="error" title="Caution">
No one can reverse a transaction once it is in a block. Anyone who claims to be "support" for Etherscan, for a wallet or for Ethereum, asks for your transaction hash and then demands your recovery phrase or an "unlock" fee, is a scammer. Type the block explorer's address in yourself; don't click on unfamiliar links.
</Callout>

## Summary

- A block explorer lets you look up any transaction, block or address yourself.
- A transaction page shows the status, the block, who sent what to whom, the fee, gas and the nonce.
- Use it to check tokens, revoke spending permissions, and verify things yourself instead of taking someone's word for it.
